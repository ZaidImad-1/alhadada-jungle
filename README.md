## ✨ Features

- 🐍 **Real snake body** — smooth bezier chain with eyes, tongue & glow
- 🎵 **Menu music** — looping jungle melody with on/off toggle
- 🔊 **Sound effects** — eat, death, level-up via Web Audio API
- 📳 **Haptic feedback** — vibration on eat, death, and D-pad
- ⛶ **Fullscreen mode** — one tap, immersive play
- 📱 **PWA ready** — install on home screen like a real app
- ⚡ **60fps canvas** — requestAnimationFrame with interpolation
- 📵 **Offline play** — works without internet after first load
- 🔋 **Mobile optimized** — reduced shadows/particles on phones

## 📱 Install as App

### Android (Chrome)
1. Open the game link in Chrome
2. Tap ⋮ menu → **"Add to Home Screen"**
3. Tap **Add** — done ✅

### iPhone (Safari)
1. Open the game link in Safari
2. Tap the **Share** button (box with arrow)
3. Tap **"Add to Home Screen"**
4. Tap **Add** — done ✅

## 🛠 Tech Stack

- **React 18** — UI & game state
- **HTML5 Canvas** — snake rendering at 60fps
- **Web Audio API** — procedural sound & music
- **Navigator Vibrate API** — haptic feedback
- **PWA** — manifest + service worker for install
- **Babel Standalone** — JSX in browser, zero build step
